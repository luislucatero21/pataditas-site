기꺼이 도와드릴게요. 아래에서 빠른 답변을 찾아보시거나 hola@rutmia.com으로 메시지를 보내 주세요. 모든 메시지를 읽어요.

기기 간에 데이터가 동기화되지 않아요
  • 두 기기 모두 같은 Apple ID로 iCloud에 로그인했는지 확인하세요.
  • iPhone 설정 → 사용자 이름 → iCloud에서 iCloud Drive가 켜져 있고 Pataditas가 iCloud를 사용하도록 허용되어 있는지 확인하세요.
  • 연결 상태와 iCloud 저장 공간이 충분한지 확인하세요.
  • 두 기기에서 Pataditas를 열고 잠시 기다려 보세요. 동기화에 시간이 조금 걸릴 수 있어요.
구입은 어떻게 복원하나요?

Pataditas를 열고 Pataditas Plus 화면에서 구입 복원을 선택하세요. 구입할 때 사용한 Apple ID로 로그인해 있는지 확인하세요. 그래도 안 되면 이메일로 알려 주세요.

Pataditas Plus는 어떻게 해지하나요?

구독은 Apple이 관리해요. iPhone에서 설정 → 사용자 이름 → 구독 → Pataditas를 열고 구독 취소를 누르세요. 무료 체험 후 요금이 청구되지 않으려면 체험이 끝나기 최소 24시간 전에 해지하세요. 결제한 기간이 끝날 때까지는 계속 이용할 수 있어요. 저희는 Apple 계정에 접근할 수 없어서 대신 해지해 드릴 수 없어요.

위젯, 제어 센터 제어 항목, 동작 버튼은 어떻게 추가하나요?
  • 홈 화면: 빈 곳을 길게 누르고 + 를 누른 다음 Pataditas를 검색하세요.
  • 잠금 화면: 잠금 화면을 길게 누르고 사용자화를 누른 다음 Pataditas 위젯을 추가하세요.
  • 제어 센터: 제어 센터를 열고 빈 곳을 길게 누른 다음 ‘제어 항목 추가’를 눌러 Pataditas를 선택하세요.
  • 동작 버튼: 설정 → 동작 버튼 → 제어 항목에서 Pataditas 제어 항목을 고르세요.
  • Siri: “Siri야, Pataditas에서 발차기 기록”이라고 말하거나 단축어 앱에서 단축어를 찾아보세요.
데이터를 내보내거나 의사에게 보여 줄 보고서는 어떻게 받나요?

의사에게 보여 줄 PDF 보고서는 Pataditas Plus에 포함돼요. 앱에서 보고서 옵션을 열고, iOS 공유 시트로 PDF를 공유하거나 저장하세요.

데이터는 어떻게 삭제하나요?

앱을 삭제하면 iPhone에 저장된 데이터가 지워져요. 개인 iCloud에 있는 사본도 지우려면 설정 → 사용자 이름 → iCloud → 계정 저장 공간 관리 → Pataditas로 이동해 데이터를 삭제하세요. 저희는 사본을 보관하지 않으므로 저희에게 삭제를 요청할 필요가 없어요.

매일 알림이 오지 않아요

설정 → 알림 → Pataditas에서 알림이 허용되어 있는지, 집중 모드나 요약 예약이 알림을 숨기고 있지 않은지 확인하세요. 그런 다음 앱에서 알림 시간을 확인하세요.

2시간 이내 10회 축하가 나타나지 않았어요

딸꾹질은 기록되지만 10회에는 포함되지 않아요. 앱은 2시간 안에 기록한 발차기와 구르기 10회를 감지해요. 그 시간대를 벗어나 흩어진 움직임은 축하를 띄우지 않아요.

Pataditas는 의료기기인가요?

아니에요. 아기의 건강을 진단하거나 평가하지 않아요. 아기의 움직임이 걱정되면 즉시 조산사, 의사 또는 산부인과에 연락하세요. NHS와 Count the Kicks의 설명은 아기 태동 세기를 확인하세요.
