支持

我们很乐意帮忙。你可以在下面快速找到答案，也可以写信至hola@rutmia.com。我们会阅读每一封来信。

我的数据没有在设备之间同步
  • 请确认两台设备都使用同一个Apple账户登录了iCloud。
  • 在iPhone的设置 → 你的姓名 → iCloud中，检查iCloud云盘已打开，并且允许Pataditas使用iCloud。
  • 检查网络连接和iCloud储存空间是否充足。
  • 在两台设备上都打开Pataditas，稍等片刻。同步可能需要一点时间。
如何恢复我的购买？

打开Pataditas，进入Pataditas Plus页面，选择恢复购买。请确认你登录的是购买时使用的同一个Apple账户。如果仍然不行，请给我们发邮件。

如何取消Pataditas Plus？

订阅由Apple管理。在你的iPhone上，打开设置 → 你的姓名 → 订阅 → Pataditas，然后轻点“取消订阅”。如要避免免费试用结束后被扣费，请在试用结束至少24小时前取消。你可以使用到已付费周期结束为止。我们无法替你取消，因为我们无权访问你的Apple账户。

如何添加小组件、控制中心控制项或操作按钮？
  • 主屏幕：长按空白区域，轻点 +，然后搜索Pataditas。
  • 锁定屏幕：长按锁定屏幕，轻点“自定”，然后添加Pataditas小组件。
  • 控制中心：打开控制中心，长按空白区域，轻点“添加控制”，然后选择Pataditas。
  • 操作按钮：设置 → 操作按钮 → 控制，然后选取Pataditas控制项。
  • Siri：说“嘿 Siri，用Pataditas记录踢动”，或在“快捷指令”App中找到对应的快捷指令。
如何导出我的数据，或获取给医生看的报告？

给医生的PDF报告属于Pataditas Plus。在App中打开报告选项，然后通过iOS的共享菜单分享或保存PDF。

如何删除我的数据？

删除App会移除保存在你iPhone上的数据。如果还要移除保存在你的私人iCloud中的副本，请前往设置 → 你的姓名 → iCloud → 管理账户储存空间 → Pataditas，并删除其中的数据。我们没有保存任何副本，所以无需请我们删除。

我的每日提醒没有出现

请检查设置 → 通知 → Pataditas，确认已允许通知，并确认专注模式或定时推送摘要没有把通知隐藏起来。然后在App中检查提醒时间。

2小时内10次的庆祝没有出现

打嗝会被记录，但不计入这10次。App检测的是2小时窗口内的10次踢动或翻身；分散在这个窗口之外的胎动不会触发庆祝。

Pataditas是医疗器械吗？

不是。它不会诊断，也不会评估你宝宝的健康状况。如果你担心宝宝的胎动，请立即联系你的助产士、医生或产科；NHS和Count the Kicks的说法请参阅数胎动。

还需要帮助？

请发邮件至hola@rutmia.com，告诉我们你的iPhone型号、iOS版本以及发生了什么。我们通常会在几天内回复。
